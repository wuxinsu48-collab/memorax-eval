# 《群侠恩仇录》题集审核与修订说明

## 结论

原题集的 50 道题大部分可以使用，但不建议直接进入正式测试。主要问题包括：

- 3 处证据无法按原文逐字回溯。
- 1 道题把双儿的询问错归给玩家。
- 1 道题建立了与原文不符的前提，即“韦小宝没有拿回所有东西”。
- 2 道题存在明显的事实错误或漏项：“几十户”被写成“十几户”，燕京街市货物漏掉干粮。
- 若干问题的计数口径、主体或心理动机不够明确。
- 工作簿经 Numbers 导出后，批次对照表的自动结果全部变为 0，且题号列表与实际批次不一致。

修订后，50 道题均具备明确问法、参考答案、独立判分点和可回溯证据。

## 修订范围

- 23 道题修订了问法、答案、判分点或证据。
- 19 道题修订了内部七类风险分类。
- 两类修订去重后涉及 29 道题。
- 50 道题均补全了“考察点（设计意图）”，将记忆维度与错误风险类型分开。
- 判分点和证据中的 `##`、换行、`|`、`｜` 已统一。
